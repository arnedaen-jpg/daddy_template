A/B 配置管理

配置接口：GET /client/api/config。判定顺序：苹果 ASN（当次 A）→ 苹果设备锁（曾命中 ASN 且上报过 UUID，永久 A）→ 黑名单 → 设备强 B（按本行 Bundle + 设备）→ Bundle 全员 B → KV。苹果 ASN 命中且带 X-Device-Id 时写入 apple_asn_lock_a_*（不按 IP 拉黑）。黑名单内 IP / 设备永远 A 面；苹果命中记备注「苹果ASN」。KV：device_force_b_* 键内绑定 Bundle 与 UUID（同一物理机在不同 Bundle 下可分别开关）；另有 apple_asn_fetched_json、bundle_force_b_*、ab_blocklist_*。

演示苹果 ASN：已开启 DEMO_MOCK_APPLE。终端执行：
curl -sS "https://ydypblkwkhblghrivwhk.supabase.co/functions/v1/daddy-ab-config/client/api/config" -H "X-Mock-Apple-ASN: 1" -H "X-Bundle-Id: com.demo.app" -H "X-Device-Id: demo-uuid"若配置了 CONFIG_AUTH_TOKEN，请再加 -H "X-Config-Token: …"。应返回 "config":"A"；带设备 UUID 时会写入 apple_asn_lock_a_* 永久 A；刷新下方请求记录可见备注「苹果ASN」、锁 A。
